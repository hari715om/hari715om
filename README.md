## What I Build

<table>
<tr>
<td width="50%" valign="top">

**[Kwixlab](https://kwixlab.com)**

AI platform with tools for PDF analysis, research assistance, resume review, and EDA. Built and deployed end to end — async task processing with Celery and Redis, subscriptions via Razorpay, running on AWS EC2 with Docker and Nginx.

`FastAPI` `React` `Celery` `Redis` `PostgreSQL` `Docker` `AWS`

</td>
<td width="50%" valign="top">

**[Entropy](https://pypi.org/project/entropy-tracker)**

CLI tool that gives every module in a Python codebase a decay score by reading its git history — not its code. Measures knowledge decay, dependency drift, churn ratio, and blast radius. Published on PyPI. Tested on Django, boto, and requests.

`Python` `PyDriller` `GitPython` `FastAPI` `Redis`
